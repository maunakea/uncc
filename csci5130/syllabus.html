CSCI 5130 - Design of Interactive Systems

Catalog Description

CSCI 5130. Design of Interactive Systems.(3)(3G) Prerequisite: CSCI 1202 or equivalent and Math 2164 or equivalent. Introduction to the design and implementation of interactive graphics systems. Raster and vector display systems, I/0 devices; graphics primitives and their attributes; raster algorithms and clipping; 2D/3D geometric transformations; 3D viewing and projections; hierarchical and procedural models; surface representation; color and lighting models; rendering algorithms; global illumination and texture mapping. (Fall, Alternate Years)

Course Outline

Introduction (1 week)
  1. Applications of computer graphics
  2. Conceptual Model for Interactive Computer Graphics
A Simple Graphics Package (1.5 weeks)
Raster Algorithms (2.5 weeks)}
  1. Points, lines, circles, polygons, polylines, text
  2. Attributes of output primitives
  3. Polygon Filling, Bitblt, Scan-conversion
  4. Anti-aliasing
Clipping Lines and Polygons (1 week)
Graphics Hardware (1 week)}
  1. Display technologies - Raster and Random Scan devices
  2. Video controller - lookup table
  3. Input/Output devices
Geometric Transformations(2 weeks)
  1. 2D/3D Affine Transformations and their properties
  2. Matrix representation and homogeneous coordinates
3D Viewing and Projections (2.5 weeks)
  1. Taxonomy of projections
  2. The Pin Hole Camera Model and the Viewing transformation
  3. Parallel and Perspective Projections.
  4. Perspective Transformation.
  5. 3D Clipping
Object Hierarchies (1 weeks)
  1. Geometric Modeling
  2. Modeling Transformations
  3. Hierarchical Structure Networks
  4. Traversal of Object Hierarchies
Shading Models (1.5 weeks)
  1. Reflectance Models - Constant, Diffuse, Specular
  2. Flat, Gouraud and Phong shading.
  3. Global Illumination Algorithms - Ray Tracing, Radiosity, Monte Carlo methods
Hidden Surface Algorithms (1.5 weeks)}
  1. Image vs. Object Precision
  2. Algorithms: Z-buffer, painter's, Warnock's algorithms, BSP trees, Ray Tracing.
Advanced Topics (time permitting): Color Models, Texture Mapping, Fractals
